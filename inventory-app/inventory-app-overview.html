Pages & Modules
🏠
Dashboard
Home screen with live alerts. Shows depleted stock warnings, overdue audits, pending PO deliveries, and quick-action task cards colour-coded by urgency.
alerts quick actions task cards
📋
Count Stock (Audit)
Physical inventory counting interface. Select store & date, enter quantities for each ingredient. Supports partial saves; highlights missing counts.
per-store per-ingredient partial save
📦
Inventory Levels
Shows estimated current stock. Single-store list view or all-stores matrix. Colour-coded low/critical indicators. Stock formula: last audit + PO receipts − sales − waste.
single store all-stores matrix low-stock badge
💳
Transactions
Lists all sales pulled from Databricks (POS) and any manual waste entries. Filter by store or date. View ingredient consumption per transaction via recipe mapping.
Databricks POS non-fiscal waste filter by store
⚗️
Recipes & Config
Master data editor. Add/remove ingredients, define product recipes (ingredient quantities per menu item), import/export config JSON. Product → ingredient mapping used site-wide.
ingredients recipes JSON import/export
🛒
Purchase Orders
Full supplier order lifecycle. Create draft POs by store, add line items (ingredient + qty), progress through Draft → Sent → Received. Receipt updates stock estimates.
draft → sent → received per-store updates stock
📊
Replenishment Report
Auto-calculates suggested order quantities (consumed × 1.05 − manual adjustments). Filterable by store. Print-friendly layout & CSV export for ordering workflow.
auto-suggest CSV export print-friendly
🔍
Variance / Loss Report
Compares actual vs expected consumption between two audits to surface unexplained losses (shrinkage, spillage, over-pouring). Colour badges at >5 % and >10 % loss.
shrinkage detection % loss badge per-store

Core Calculation Formulas
Estimated Current Stock
last_audit_count
+ sum(received_PO_lines)
− sales_consumption
− manual_transactions
Calculated per ingredient per store. Refreshes when PO received or new audit saved.
Replenishment Order Quantity
ceil( consumed_7d × 1.05 )
− adjustment_delta
5 % safety buffer above recent consumption. Minus any positive manual adjustments already applied.
Unexplained Variance (Loss)
actual_consumed =
opening_stock − closing_stock
+ PO_receipts_in_period

variance_pct =
(actual − expected) / expected × 100
Expected = sales-derived consumption via recipes. Period = two most-recent audits.
Low-Stock Threshold
daily_avg = consumed_7d / 7
low_stock = stock < daily_avg × 3
Flags if less than 3 days of supply remain. Shown as critical alert on Dashboard.

State & Persistence Layers
⚙️
config (localStorage)
Ingredient definitions and product recipe mappings. Exported/imported as JSON. Shared across all pages.
🗄️
data (localStorage)
Operational records: audits, manual transactions, purchase orders, auto-increment ID counters.
📡
salesCache (localStorage)
Cached Databricks query results with lastRefreshDate. Deduplication on merge prevents double-counting.
🔑
settings (localStorage)
Databricks PAT token and SQL warehouse ID. Never sent to any server except the Databricks endpoint.
